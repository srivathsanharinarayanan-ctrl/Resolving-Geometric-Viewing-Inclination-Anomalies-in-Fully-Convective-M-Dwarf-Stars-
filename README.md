# Resolving-Geometric-Viewing-Inclination-Anomalies-in-Fully-Convective-M-Dwarf-Stars
A data pipeline that uses optimization modeling to fix tilted viewing angles in space data. It unmasks fast-spinning stars that look quiet to automated telescopes and helps prove how magnetic fields form in low-mass stars.
The stellar properties and raw kinematic parameters for the M-dwarf sample utilized in this study were aggregated from several primary public astronomical databases. Target selection, baseline effective temperatures, and stellar radii were established using the Transiting Exoplanet Survey Satellite (TESS) Input Catalog (TIC) and the Kepler/K2 archives. Precise astrometric measurements, parallaxes, and absolute magnitudes were obtained from the Gaia Data Release 3 (DR3) archive. Cross-matching of stellar identifiers and atmospheric data was conducted via the SIMBAD and VizieR services provided by the Centre de Données astronomiques de Strasbourg (CDS). Confirmed planetary properties and habitability constraints were cross-referenced with the NASA Exoplanet Archive.
